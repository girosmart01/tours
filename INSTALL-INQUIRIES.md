# Обновление: подбор экскурсии и короткий запрос

## Установка
1. Скачайте и распакуйте tours-october-calendar.zip.
2. В GitHub girosmart01/tours откройте ветку, подключённую к Railway.
3. Загрузите содержимое архива в корень репозитория с сохранением папки images.
4. Заменить: app.js, index.html, style.css, main.py. Добавить: inquiries.py и schedule.json.
   PHOTO_CREDITS.md и images/rafting.jpg включены для тех, кто пропустил предыдущее обновление.
5. Зафиксируйте все файлы одним коммитом. Серверные main.py и inquiries.py обязательны: старый сервер не поддерживает короткую форму.
6. Дождитесь успешного деплоя Railway и заново откройте Mini App.
7. Отправьте один контрольный запрос из Telegram и убедитесь, что менеджер получил уведомление.

Архив подготовлен на основе файлов проекта, предоставленных в этом чате. Если main.py менялся после них, перед заменой нужно сверить изменения. Код не опубликован автоматически.

## Поведение
- Подбор в личной переписке с @igiro01, с названием выбранной экскурсии в черновике сообщения.
- Короткая форма: дата или «Пока не определился», взрослые, дети, курорт.
- Если есть Telegram username, дополнительный контакт необязателен; иначе он нужен для ответа.
- Запрос не является подтверждением брони; оплаты на этом этапе нет.
- Рафтинг: только взрослые; указанная дата должна приходиться на пятницу.
- Коллаж возвращён во вкладку «Отзывы». Добавьте images/reviews-collage.png. Ссылка на канал ещё не предоставлена.

## Данные и сервер
Старый /api/book и таблица bookings сохранены. Новый /api/inquiry сохраняет запросы в отдельной таблице inquiries той же базы DB_PATH. Таблица создаётся автоматически, очистки базы нет. Старый экспорт /api/bookings.csv содержит только прежние заявки, не новые запросы. Новые запросы отправляются менеджеру ботом.
При недоставленном уведомлении запрос сохраняется, пользователь получает сообщение и ссылку на менеджера. Автоматического повтора уведомления нет.
Раздача статических файлов ограничена index.html, app.js, style.css и папкой images; база и исходники через сайт недоступны.
DB_PATH и постоянное хранение базы в Railway остаются вашей текущей настройкой.

## Проверка
Локально проверены все 8 форм, отсутствие даты, передача количества людей, контактные ссылки, мобильная ширина 320 px, ограничения рафтинга и сообщение о недоставке. Сервер проверен с тестовой SQLite: сохранение, проверка авторизации/контакта/дат, запрет выдачи служебных файлов. Настоящие сообщения не отправлялись; доставка рабочим ботом требует контрольного запроса после деплоя.

## Календарь октября 2026
Рафтинг — пятницы; Золотое кольцо — понедельники (повторяются и в следующих месяцах). Сокровище Цейлона, Сафари, Элла, Элла + Сафари — только опубликованные даты октября. В других месяцах для этих четырёх туров даты недоступны до обновления расписания. Для Канди и китов расписание не предоставлено: будущая желаемая дата согласуется с менеджером. Прошедшие даты закрыты по времени Шри-Ланки. Можно отправить запрос без выбранной даты.
Ограничения проверяются в календаре и на сервере. Для многодневных туров выбирается дата выезда, рядом показывается весь период.
Календарь проверен на ширине 320 px и по каждому дню расписания.
