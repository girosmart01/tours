# Обновление каталога и формы заявок — 30 сентября 2026

## Что изменено
- Добавлены «Золотое кольцо Шри-Ланки» и «Рафтинг по горной реке».
- Обновлена существующая экскурсия «Канди + Питомник слонов»; её id сохранён.
- В каталоге 8 экскурсий. Новые программы представлены адаптивными карточками HTML/CSS.
- Канди: порядок остановок по предоставленному изображению, включая аюрведический сад; 85$ при любом размере группы; детские скидки.
- Золотое кольцо: 250$ с Пидурангалой или 280$ с Сигирией; одноместный номер +25$ за ночь, то есть +50$ за две ночи.
- Рафтинг: 18+, по пятницам, с инструктором и снаряжением. 75$ при группе 10–12, 100$ при группе 5–8; для 9 участников и другого неуказанного состава — запрос менеджеру. Поезд удалён из программы.
- Для всех восьми туров работает полная форма: желаемая дата, имя, телефон, страна, отель и номер комнаты. Дата выбирается календарём и подтверждается менеджером; это заявка, а не гарантия выезда. Рафтинг — по пятницам, 18+. Прошедшие даты не принимаются интерфейсом.
- Исправлены повтор «на человека / за человека» и отображение многодневной даты на границе месяца; прошедшие даты скрываются.
- Бэкенд, API и база заявок в этом пакете не меняются. Для всех туров используется существующий API /api/book с прежними полями.

## Установка в существующий GitHub-проект girosmart01/tours
1. Распакуйте архив. Не загружайте сам ZIP вместо файлов сайта.
2. Замените в корне репозитория app.js, style.css и index.html.
3. Добавьте images/rafting.jpg в существующую папку images. Сохраните все остальные фотографии.
4. Сохраните PHOTO_CREDITS.md вместе с проектом.
5. Зафиксируйте изменения. Если автодеплой Railway подключён к этой ветке, он запустится автоматически. В противном случае запустите деплой этого коммита в Railway вручную.
6. После успешного деплоя полностью закройте и снова откройте Mini App в Telegram. В HTML добавлен новый параметр версии CSS/JS для обновления кеша.

Открытый на Railway сайт автоматически от выдачи этого архива не меняется. Публикация данным пакетом не выполнялась.

## Проверка
Проверить 8 карточек, обе цены Золотого кольца, последовательность Канди, отметку 18+ и включённое снаряжение в рафтинге. Все восемь туров должны открывать форму заявки с календарём и контактными данными. Полная отправка всех восьми форм проверена на локальном тестовом API; реальные заявки не создавались. Проверены ограничение пятниц для рафтинга, запрет прошлых дат и повтор после ошибки API. Рабочая отправка требует запуска внутри Telegram; доставка уведомлений реальным ботом не тестировалась.

Подпись под фото рафтинга убрана из каталога и страницы тура. Обязательная атрибуция доступна во вкладке «Вопросы» → «Источники фотографий».
