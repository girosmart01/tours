НОВЫЙ ПОРЯДОК ТУРОВ + НОЯБРЬ 2026

1. Распакуйте tours-november-order.zip.
2. В GitHub girosmart01/tours откройте ветку Railway.
3. Через Add file → Upload files замените В КОРНЕ app.js, index.html и schedule.json.
4. Зафиксируйте все три файла одним Commit changes.
5. Дождитесь успешного деплоя Railway и переоткройте Mini App.
Не загружайте ZIP или внешнюю папку архива.

Порядок каталога и списка выбора тура:
1. Элла
2. Сафари
3. Сокровище Цейлона
4. Элла + Сафари
5. Морская экскурсия к китам
6. Канди + Питомник слонов
7. Рафтинг по горной реке
8. Золотое кольцо Шри-Ланки

Форма без ранее выбранного тура по умолчанию показывает Эллу. Кнопка в конкретной карточке по-прежнему открывает именно выбранный тур.
Сохранены цены, описания, фотографии, контакты и формы. Включено ноябрьское расписание из предыдущего обновления. Отдельно предыдущий архив устанавливать не нужно.
